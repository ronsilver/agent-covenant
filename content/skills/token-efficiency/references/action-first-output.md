# Action-First Output Structure (10 Rules)

Source: master catalog #155 i-have-adhd. Structure every agent response for immediate action, not passive reading.

## The 10 Rules

1. Lead with the next action — the first line states what happens next, not what was done.
2. Number multi-step tasks — numbered steps for anything longer than one action.
3. End with one concrete next step — exactly one, never a menu.
4. Suppress tangents — anything not needed for the next action stays out.
5. Restate state every turn — assume the reader lost the thread; one line of current state.
6. Specific time estimates — minutes, not "soon" or "later".
7. Make wins visible — completed items marked done in the numbered list.
8. Matter-of-fact errors — state the error, the impact, and the fix; no drama.
9. Cap lists at 5 — beyond five items, group or prioritize.
10. No preamble, recap, or closers — start with rule 1, end with rule 3.

# Logical Fallacy Reference

## Circular Logic
"X is correct because X is the standard approach."
Fix: demand external evidence.

## Confirmation Bias
Reads 3 files supporting A, skips file contradicting A.
Fix: "What would prove this wrong?"

## Premature Convergence
Locks on first solution with <=1 alternative.
Fix: "List 3 approaches. Pick best. State why others rejected."

## Authority Over-Reliance
"Docs say X" without checking if docs are current/correct.
Fix: cross-validate docs vs code vs tests.

## Causal Confusion
"Changed X, Y broke, so X caused Y."
Fix: reproduce Y with X reverted.

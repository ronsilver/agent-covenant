## Decision

Per GATE-ANSWER sheet v2 (host-approved 2026-08-24):

- G1: ACCEPT PolyForm-Noncommercial-1.0.0 license — framework is per-personal-use (MIT repo, distributed for individual setups); gitnexus is a dev-time dependency; NC restriction documented in this ADR; no commercial redistribution intended.
- G2: register — conserve all 9 skills in `content/skills/gitnexus-*`, add to manifest.yaml + manifest.example.yaml. Double-management with `.claude/skills/gitnexus/` (analyze-managed) documented as residual.
- G2a: add ONLY `license: PolyForm-Noncommercial-1.0.0` to each of the 9 SKILL.md frontmatters (1 line; REQUIRED by validate.sh `license` field for registered skills). Body untouched. `metadata:` optional per validate.sh — NOT added.
- G2b: exempt evals/quality — `scripts/validate-evals.py` EXEMPT_SKILLS += gitnexus-\* — precedent: graphify's user-mandated allowlist; `scripts/validate-skill-quality.py` EXCLUDE += gitnexus-\* — precedent: `_TEMPLATE`, `new-skill`.
- G3: add MCP server — `npx -y gitnexus@latest mcp` (stdio, bare binary, portability-compliant) to `content/mcp/mcp.json` + `content/mcp/opencode-mcp.json` + README tables. No user-global MCP exists (falsified: only hooks in `~/.claude/settings.json:56,78`) → no conflict.
- G4: keep all 9 registered skills (pdg-query, pr-review, taint-analysis included; never-deployed status noted).
- G5: new ADR covers the 4 Core file edits (this ADR).
- G6: counts — 71 skills (63 − graphify + 9 gitnexus) / 12 MCP servers (12 − graphify + gitnexus).
- G7: remove CLAUDE.md — untracked file, NOT generated by `make sync`; created by `gitnexus analyze`; AGENTS.md is canonical. Analyze may regenerate it (re-remove if it reappears; or disable auto-commit — no action now).
- G8: dirty tree (in-flight subagent work) untouched: `AGENTS.md`, `content/subagents/README.md`, `content/subagents/_TEMPLATE/SUBAGENT.md`, `docs/reference/subagent-permissions.md`, `docs/reference/subagent-schema.md` (all modified tracked). AGENTS.md itself IS updatable by this migration if needed (verified: zero graphify hits — no change required).

Core-skill doc edits (4 files, P5): `content/skills/context-management/SKILL.md:282`, `content/skills/context-management/references/staleness-protocol.md:40`, `content/skills/context-management/references/dependency-graph-retrieval.md:35`, `content/skills/engineering-standards/references/eval-harness.md:56`.

## Consequences

Positive:

- Single code-intelligence tool (graphify removed, gitnexus adopted).
- Bare-binary MCP portability (stdio, `npx -y gitnexus@latest mcp`).
- Skills installed per-user via manifest/sync (9 registered gitnexus skills).

Negative / residuals:

- NC license — personal use only (framework remains MIT; gitnexus content carries its NC license via `license:` frontmatter).
- Double-management: `.claude/skills/gitnexus/` (analyze-managed, 6 skills) coexists with sync-deployed `content/skills/gitnexus-*/` (9 registered). `gitnexus analyze` may regenerate the former and may regenerate CLAUDE.md.
- `.gitnexus/` index maintenance required (analyze-managed; gitignored).
- Evals/quality exemptions for tool-generated skills (documented, no silent validator weakening).
- validate-no-fintech.sh file exemption for tool-generated gitnexus-* skills (same documented-exemption class as evals/quality; mechanism: is_exempt_file).
